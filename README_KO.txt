NIMROD — 15단계 착륙 절벽·축제 시스템 재검토본 (2026-10-16)
Godot 4.3 stable / GDScript / GL Compatibility / 1280×720 canvas_items

실행
실행 ZIP 전체를 새 폴더에 풀고 Nimrod/project.godot을 Godot으로 가져옵니다.
첫 이미지·음원 임포트가 끝난 뒤 실행합니다. 게임 실행에는 Python이 필요 없습니다.
Windows 실행 보조 파일은 PLAY_WITH_GODOT.bat이며 GODOT_BIN으로 엔진 경로를 지정할 수 있습니다.

현재 범위
착륙 절벽 배치를 다시 만들고 축제 터·색끈·불씨·귀환 잔교·저장 스키마3을 적용했습니다.
나머지9지역의 지형과 아트, 니므롯 구간의 스프라이트·전투 데이터·대사는 기준 검토본 그대로입니다.
착륙지 승인 후 나머지9지역 지형을 진행합니다. 상세 가정값과 완료/대기 항목은
 docs/STAGE15_MAP_REWORK_REPORT_KO.md를 확인합니다.

조작
A/D: 이동. S: 웅크리기. Space: 점프. S+Space: 일방향 선반 아래로 내려가기.
J: 현재 무기 공격. K: 회피. E: 상호작용·대화 넘기기. 대화 중에는 시간이 멈춥니다.
시야우와르샨의 단검은 기존5타 콤보와 5타 빛 파동을 유지합니다.
자불리스탄에서 Q 질주, F 시야(누름 유지), R 천륜 빛 투척은 해당 공명을 얻은 뒤 사용합니다.
이중 점프는 공중 Space, 벽의 발톱은 벽에서 A/D, 벽 차오르기는 벽에서 Space입니다.
벽 차오르기는 따로 얻을 수 있지만 벽의 발톱이 있어야 쓸 수 있습니다. 기어가기는 S+A/D입니다.
M: 지도 열기/닫기, Esc: 일시정지. 둘 다 게임 시간이 멈춥니다. 미니맵은 없습니다.
니므롯의 R 아누르의 빛·L 먹어치우기·훔바바 폼은 기존 규칙을 유지합니다.
F5: 저장 파일과 모든 진행을 지우는 완전 초기화. 새 니므롯 게임으로 시작합니다.
F6/F7 단계 디버그 이동은 기존처럼 동작합니다. Ctrl+G는 공명 전체 지급, Ctrl+B는 회수입니다. 일반 배포의 F3 월드 오버레이는 꺼져 있습니다.

자불리스탄 진입·시도
흐와니라 광장에서 라오다스타흐마에게 단검을 받은 뒤 다시 대화를 마치면 이동합니다.
매번 착륙지에서 시작합니다. 월드 전체는 하나로 이어지며 청크 경계 페이드·방 ID는 없습니다.
축제 터에서 얻는 7공명은 이번 시도에서만 유지됩니다. 죽거나 살아서 귀환하면 전부 사라집니다.
한 번 발견한 축제 터의 위치와 능력 아이콘은 지도 지식으로 남습니다.
전투 화면에는 기본HP/무기와 작은 능력 아이콘만 표시하며 수집·죽음 숫자는 지도/일시정지에 있습니다.

수집·귀환·저장
축제의 색끈은 영구 수집품입니다. 4개마다 최대HP+10, 상한200이며 줍는 즉시 회복하지 않습니다.
축제의 불씨는 봉헌용입니다. 일반 배치60개와 보스 첫 처치당5개이며 일반 적은 불씨를 드롭하지 않습니다.
죽으면 운반 불씨와 공명이 즉시 사라지고 흐와니라 광장에서 HP를 전부 회복합니다.
색끈·열린 문과 지름길·처치한 보스·지도·축제 터 지식·죽음 횟수는 유지하고 광장에서 자동 저장합니다.
귀환 잔교는 착륙지와 세 보스 근처, 총4곳입니다. E로 살아서 돌아오면 광장 화로에 불씨를 전량 바칩니다.
0개로도 귀환할 수 있으며 생존 귀환은 죽음 횟수를 올리지 않습니다. 귀환 뒤 HP완전회복·자동저장을 합니다.
자불리스탄 안에서는 수동·자동·체크포인트 저장이 모두 차단됩니다. 종료하면 마지막 광장 저장으로 돌아갑니다.
세이브 스키마3은 구 스키마2의 기존 이야기·문·보스·지도·죽음 기록을 읽되 구 능력과 생명 조각은 버립니다.
