## 새 흐름

딜문 도착 → L 포식과 폭주 게이지 해금 → x≈4500의 시마티에게 E → 9줄 대화 → 종이 전달 0.6초 → 시마티가 2초에 걸쳐 사라짐(노점은 유지) → x=8800 이동 구역에서 E → 죽음의 바다. 종이가 없으면 이동하지 않고 안내만 표시한다.

죽음의 바다는 너비1800, 지면880이며 실제 걷는 섬은0~1400이다. 양쪽에 보이지 않는 고체 벽이 있다. 우르샤나비는x=900의 바위에 앉아 두 주사위를 굴리며 대화·승선 상호작용은 없다. 배는x=1300 부근에 놓았다.

## 시마티 대사 원문

1. 니므롯: 개척되지도 않은 이 땅에서 무엇을 팔고 있는거요?
2. 시마티: 난 무언가를 팔고 있는 것이 아니야. 당신의 운명 속 한 명의 등장인물일 뿐이지.
3. 니므롯: 그렇다면 당신은 나에게 영생과 부활에 대해서 알려줄 수 있겠어?
4. 시마티: 아쉽게도 그 역할을 맡진 않았지.
5. 니므롯: 기대하던 대답은 아니군. 아, 이제 어디로 가야하지? 난 이제 마지막이야.
6. 니므롯: 아누르의 빛이 비치는 딩이르의 별들을 모두 돌아다녔어.
7. 시마티: 저 너머, 죽음의 바다라고 불리는 공간을 넘으면 우트나피쉬팀이라고 하는 자가 있지.
8. 시마티: 그는 아주 오래전에 죽음의 바다에 빠져 죽은 이후 계속 되살아나고 있어. 내가 직접 보았지, 정말 신기하더군. 십만 년보다 오래 살 수 있다니.
9. 시마티: 죽음의 바다를 건너기 위해서는 이게 필요할 거야.

## 선택 메뉴와 폭주

샴하트의 첫 대화 또는 새 단계 첫 대화 후 E를 누르면 대화하기·저장하기가 표시된다. 폭주가 해금되면 폭주 완화 주문이 추가된다. W/S 또는 방향키로 선택하고 E로 확인, Esc로 닫는다. 대화하기의 반복 대사는 축복을 받은 뒤에도 남는다.

| 항목 | 값 |
|---|---|
| 포식 | 전방180px의 가장 가까운 살아 있는 적, 150 고정 피해, 쿨다운15초 |
| 연출 | 0.15초에80px 전진, 전체0.7초, 타격0.35초 |
| 증가 | 포식+12, 정도50이상에서 도끼·충격파 처치+1(적마다 한 번) |
| 점당 수정자 | 공격력·공격속도·최대HP 각각+3%, 공격속도 합계 상한2배 |
| 단계 | 30초과/40초과/50초과/90초과 |
| 단계 추가 피해 | ×1.05/1.10/1.15/1.25 |
| 단계 도달 거리 | ×1.00/1.10/1.15/1.25 |
| 치료 | HP30을 지불하고−11; HP31이상 필요 |
| 사망 | 기본91이상, API 유예 중에도100이면 사망; Y와 무관 |

R 아누르의 빛, L 포식, F5 새 런, F6/F7 개발용 단계 이동. Y는 개발용 HP 하한 토글이며 화면 상태 표시는 없다. 대화 중 E는 현재 한 줄을 건너뛰며 시작0.25초·연속0.12초·종료0.2초 보호 시간을 적용한다.
