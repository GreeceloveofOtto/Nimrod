# NIMROD 3단계 구현 보고서

NPC 이름표·가독성 처리, 근미래 복식 재디자인, 루갈성 정문 앞 `CastleFront`(폭 4400), 범용 대문 제어를 추가했습니다. 플레이어·기존 전투 수치는 유지하며 이제 8개 레벨을 탐험할 수 있습니다. 기존 Stage 2 보고서는 이력으로 보존합니다.

## 변경 내용

- 모든 NPC 루트 아래 `NameTag`(PanelContainer/Label)를 만들었습니다. 발 아래 14px, 가운데 정렬, HUD와 같은 한국어 폰트 18px, 외곽선 없이 그림자·반투명 패널을 사용합니다. 텍스트 변경 후 다음 프레임에 크기를 읽어 다시 정렬하며 sprite flip과 독립적입니다. 플레이어에는 이름표가 없습니다.
- 의상 대비, 5px/40%의 따뜻한 내부 림라이트, 생성 이미지 빛 웅덩이·접지 그림자, 배경에만 톤 다운, 220px 근접 밝기 1.12·이름 알파 1.0을 적용했습니다. 근접 보간 시간은 0.15초입니다. 문·소품·플레이어·적에는 배경 dim을 적용하지 않습니다.
- 루갈반다·닌순·샴하트·인안나·팝수칼은 디자인 시트 → 오른쪽 정지 이미지 → 6프레임 숨쉬기로 교체했습니다. 640×640, 발 앵커 [320,600], 2.4초 루프를 유지합니다. 팝수칼은 여성 호위이며 키 비율은 1.00입니다.
- 토인 조형·동작 시트는 재사용합니다. 새로운 인물을 생성하지 않고 기존 생성 픽셀의 허용된 내부 림라이트만 보강했으며 원본 PNG는 `_legacy`에 보존했습니다. 스프라이트 표시 배율만 기존 0.30에서 0.39로 늘렸습니다. 발 앵커와 NPC 위치는 유지됩니다.
- `GateController`가 문지기 제스처·프레임 3 열림·근접 개폐·충돌 벽·선택적 자동 이동을 담당합니다. `VillaGate`는 이전 API와 설정을 유지하는 얇은 호환 래퍼입니다. 루갈성 대문은 같은 맵 안에서 통과하고 별장 대문은 기존처럼 자동 이동합니다.
- `CastleF1` 정문 잠금을 해제했습니다. F1 정문 x150 → 정문 앞 x3900, 정문 앞 문 x4000 → F1 x220으로 왕복하며 HP·상태를 유지합니다. 사망은 기존 RearGate x260/HP180 복귀입니다.
- `CastleFront`에는 근접 2마리·원거리 1마리, 60px 단차, y700의 일방향 발판 2개, x2300부터 안전 구역, x2520/3280 문지기, x2900 루갈성 대문이 있습니다. x480 도심 통로는 잠겨 있으며 `DowntownPassage_F1` 문자열만 저장합니다. E 입력은 잠김 효과음·흔들림·"아직 들어갈 수 없다" 토스트만 표시합니다.
- 새 대문 효과음 2종과 48초 `castle_front` BGM을 추가했습니다. 기존 문 음원은 재사용합니다.

## 이미지 생성·검증

모든 신규 NPC·문·배경·소품·지형·FX는 실제 이미지 생성 도구의 PNG에서 패킹했습니다. 원본과 전체 프롬프트는 `assets/source_art/stage3/`, 에셋별 규격·프롬프트는 `assets/image_prompts/stage3_*.md`에 있습니다. `tools/build_stage3_assets.py`로 재현합니다. `pack_sprites.py`의 크로마키·크롭·공통 스케일·앵커 정렬·패킹, 타일 원본 경계 블렌드와 요청에서 허용한 breathing/rim만 사용합니다. 기존 왕족 시트·manifest 및 작업자 원본 PNG는 `assets/sprites/npcs/_legacy/`에 보존합니다.

통합 validator: **PNG105개, 누락0, 오류0**. NPC 모든 프레임의 높이비율±3%, 발 앵커, sheet/manifest·프레임 수·알파·fps, 새 4400px 맵의 시차 폭과 바닥 타일 경계가 통과했습니다. 신규 바닥 및 기존 성 바닥·옥상 타일의 생성 마젠타 여백은 각각 기존 원본 내부 크롭으로 제거했으며 불투명 타일에 키 색상이 남지 않는 것도 확인했습니다. **필수 미생성 에셋: 없음.**

평균 휘도 대비 검사는 빛 웅덩이·근접 하이라이트·소품을 제외한 보수적 비교이며 실패로 처리하지 않습니다. 재디자인 5명은 모두 차이30을 넘습니다. 재사용 작업자 중 경고4개가 있습니다:

| 위치/NPC | NPC 평균 | 배경 평균(bg_dim 적용) | 차이 |
|---|---:|---:|---:|
| RearGate 문지기 |72.5|48.9|23.6|
| VillaF1 하인A |83.4|66.6|16.8|
| VillaF1 하인B |83.6|69.0|14.5|
| CastleFront 바깥 문지기 |72.5|43.1|29.4|

이름표·림라이트·빛 웅덩이로 실제 화면의 인물 위치는 읽히지만, 작업자 의상을 포함한 전체 화면 대비 개선에는 **배경의 인물 활동 높이대(바닥선 위 0~320px) 대비·채도를 낮춘 재생성 필요**가 남습니다. 이번 단계에서는 기존 배경을 재생성하지 않았습니다. 토인 확대는 원본 픽셀을 보간하므로 얼굴·작업 소품 세부를 더 선명하게 하려면 **토인 시트 재생성 권장**입니다.

새 WAV2종과 BGM은44.1kHz/모노/16bit, 정확한 길이, 피크≤-3dBFS입니다. 48초 BGM의 반복 이음새도 확인했습니다. 메인 씬을 통해 기존·신규 레벨 전환을 실제 실행하며 단일 플레이어·HP 보존·도착 문 닫힘을 검사합니다. GDScript 임포트·파싱도 통과했습니다.

실제 렌더 결과는 `docs/screenshots/stage3_*.png`의12개 1280×720 화면(기존8뷰와 정문 앞 도착/대문/도심/전투4뷰)입니다. 가상 디스플레이에서 VSync 설정 불가 경고가 있습니다. 대문 애니메이션 도중 레벨 교체 시 중단된 Tween의 finished를 기다리던 잔여 상태를 수정했고, 취소 후 기다리던 호출이 반환되는 회귀 검사도 추가했습니다. ObjectDB 누수 경고는 제거했습니다. Godot 4.3의 verbose 종료 로그에는 StringName(timeout) 1개 미반납 진단이 남지만 실행 오류·ObjectDB 누수는 없습니다. 가상 디스플레이의 VSync 경고와 함께 실제 Windows/GPU 종료 검증은 미실행입니다.

배포는 승인된 별도 브랜치 `codex/nimrod-rear-gate-godot43`에 저장합니다. main은 변경하지 않습니다. 커밋 ZIP의 실제 HTTP 다운로드·CRC·파일 바이트 일치와 새 폴더의 Godot4.3 임포트/실행을 확인해 전달합니다.

## 미실행·제한

- 실제 스피커 청감·Windows GPU/배치 실행·장시간 사람의 직접 플레이: 작업 환경이 Linux 자동 실행이므로 미검증.
- 미적 완성도(얼굴·캐릭터 매력·머리카락/소매 자연스러움)는 생성 후보·축소 화면을 검토했으며 사람의 취향 평가는 별도로 필요.
- 도심 통로 내부, NPC 대화·스토리 분기·최종 엔딩은 이번 범위가 아니며 만들지 않음. 도심 문은 잠긴 연결 자리만 있음.
- 필수 이전 기반 누락 없음. 새 `GateController`, `CastleFront`, rim/대비 검사 도구·데이터를 추가했음.
