# NIMROD 10단계 구현 보고

기반: 9단계 d24b129b, Godot 공식4.3/GL Compatibility/1280×720. 작업 전 기준 검사는108/108 통과했고 에셋은49.793MiB였다. 삭제 요청한 wall_trunk_tile 이미지와 삼나무 숲 두 층의 고체 벽30개는 이미9단계에서 삭제됐으며 다시 생성하지 않았다. 배경 숲과 실제 가지 발판은 유지한다.

## 기능과 선택

Story의 누적 단계를15까지 확장했다. 기존 variants/그룹 대화와 컷신 러너를 재사용한다. F6/F7은 한 팔·의수·스킬·멜람무·투구 수정자를 함께 갱신한다. 사망/F5는 플래그·장비·무기·수정자를 지우고 집에서 맨손/두 팔로 시작한다. 기존 이동·HP180·도끼20/20/20/22·구르기0.48/무적0.25·방향 캔슬·콤보 리셋0.8·아누르R을 유지한다.

훔바바의 최초 공격은 컷신으로 입력과 피해를 잠근 뒤 할퀴기 선딜0.6초→필중14(최소HP1)→히트스톱0.3초/붉은 플래시0.15초/흔들림→arm_loss_hit0.5초+대기1.0초다. 구르기나 공중 상태도 회피할 수 없다. 구르기 중 맞아도 안전한 서 있는 충돌 박스를 복원한다. arm_lost 이후 무기는도끼로 고정하고 지팡이 줍기를 비활성화한다. 한 팔 수정자는0으로 페널티가 없다. 첫 일격은 한 런에 한 번이다.

훔바바 사망 클립 이후 멜람무를 드랍한다. 삼키기 전까지 출구는 잠겨 있고, 재입장해도 멜람무가 복구된다. 멜람무 공격력+10%/고정 최대HP+20, 심장박동2초·붉은 비네팅·토스트2.5초 후 집으로 자동 이동한다. 집 스폰(470,620), 침대 엔키두아 앵커(320,520), 인안나(900,620)다. 침대 NPC는3방향을 사용하지 않고 깨어 있음/잠듦 클립을 쓴다. 마지막 장면은 암전2.0/유지1.5, 피 얼룩 침구와 한 팔 니므롯, 밝아짐2.0, 오열6.0/줌1→1.15, 다시 암전2.0 후 시간 경과다. 신체 훼손을 직접 그리지 않는다. 끝나면 혈흔·컷신 세트·카메라·무기 표시·입력을 복구한다.

최대HP는 round((180+고정 증가 합계)×(1+비율 증가 합계))이며 최대치가 늘어난 만큼 현재HP도 증가한다. 공격력/속도는 기존 합산 방식, 속도 상한2.0이다. 투구는 공격력+5%/고정HP+15, 의수는 공격력+20%/속도+10%/고정HP+30이다. 투구 외형은 요청대로 플레이어 시트에 덧붙이지 않는다. 멜람무 폭주·포식과 딜문 이후 이야기는 이번 범위에 넣지 않는다.

HomeFront:너비2600/바닥880, 집 스폰500, 보스1700, 집 문400, 일방향 발판x800/1800·높이130·폭300. 구갈안나는 대화 전에는 공격하지 않고 피해도 받지 않는다. HP2000/몸380×420/턴0.80/슈퍼아머/넉백10%. 지진18·스턴0.5·전파1500·높이60·쿨7, 돌진25·속도1100·거리1800·벽 기절1.2·쿨6, 솟구치기20·판정320×300, 필살기35·반경560/높이300·전방만·쿨18(HP절반 이하12). 후딜을 보장하고 같은 패턴 연속 사용을 피한다. 경고 영역만 코드UI로 그리며 보스/충격파/번개/먼지는 생성 이미지다. 사망2.4초 후 투구가 나오며 장착3초 후 이동하거나 집 문E로 자동 장착하고 이동한다.

별장3층 Spawn_FromSkip(700,620), 의수 장면 후 위 문을 해제한다. 별장4층은2200/바닥620, 우주정은x1500 중심이며 실제 착륙 다리로 접지 검사한다. 혼잣말2줄 후5초 걷기와4초 페이드를 동시에 진행한다. 딜문9000/바닥880/착륙600, 우주정420 중심만 있고 괴수·NPC·문·아이템은 없다. 가장자리260px 이내에서 비네팅이 나타난다.

## 이미지·용량 정책

한 팔/의수 각18개 공통 클립, 한 팔 추가2개, 컷신2개, 엔키두아 침대2개, 구갈안나17개와FX4개, 소매FX/멜람무/투구/침구/우주정, 새 배경·타일을 이미지 생성 도구로 만들었다. 프레임 수·길이·공격 도달 범위는 기존 도끼의 원본 포즈 경계로 정규화한다. 같은 앵커640/[320,600]과 키363±3%를 유지한다. 의수는 왼팔만 흰 금속/청동, 한 팔은 왼쪽 어깨의 짧은 붕대 소매로 표현한다. 잘못 생성된 양팔 이미지와 초기 후보는 archive/stage10/rejected에 보관했고 정상 후보를 선택했다. 원본·변환 전·개발 파일은archive에 보존한다. 신규 이미지는 모두 생성했으며 미생성 목록은 없다.

화질은SSIM≥0.93/RGB평균차≤3/알파평균차≤0.5/bbox불변 기준을 유지하며 실제 표시 크기를 바꾸지 않고 저장 크기만 줄인다. 논리 프레임을 유지하는 frame_map으로 지각적 중복을 합친다. 용량 결과·미달 항목·추가 후보는 SIZE_REPORT_KO.md에 기능 검사와 분리해서 기록한다.
