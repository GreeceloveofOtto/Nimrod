## 지형과 렌더링

고체 덩어리를 기본으로 두고 실내 홀·복도·두 개의 수직 우물을 손설계 ASCII로 파냈습니다. 컴파일러는 좌표에 적힌 템플릿만 펼칩니다. `:`는 뒷벽 없이 바다 원경이 보이는 외부 공간, `^`는 병합 충돌을 가진 천장 가시, `F`는 기존 시야 게이트와 함께 열리는 암반 그림입니다.

표면에는 생성 사암 테두리, 한 칸 안쪽에는 전이층, 깊은 내부에는 거의 검은 저대비 생성 타일을 사용합니다. 벽돌 뒷벽에는 접합 마스크에 따른 어둠이 포함되어 있습니다. 생성한 사슬·까치발·목재 지지와 소금 서리 스트립으로 발판을 지지하고, 기존 등잔 광원 이미지를 재사용했습니다. 벽·배경·소품을 `_draw()`나 절차적 이미지로 만들지 않았습니다.

공용 TileSet·충돌 Shape·가산 광원 재질을 공유하고, 생성 후 임시 행/장식 버퍼를 해제했습니다. 충돌 병합용 방문 사전을 2,304바이트 비트맵으로 바꿨으며 비동기 이미지 요청은 캐시에 들어간 뒤에도 반드시 회수해 종료 시 Image/RID가 남지 않게 했습니다. 플레이어 충돌·이동 코드와 4행/step 생성 간격은 바꾸지 않았습니다. 새 문자열 RLE는 구 배열 RLE와 함께 읽으며, navigation은 청크에서 한 번 복원합니다.
