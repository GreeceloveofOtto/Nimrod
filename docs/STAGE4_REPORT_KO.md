### 공격 프레임 정합

번호는 **1부터 시작**, 균등 프레임은 `floor(t / duration × frames)+1`입니다. end는 다음 프레임 경계에 닿을 수 있고 실제 판정 종료 조건은 유지합니다.

| 공격 | 프레임/길이 | active 초 | 시작~끝 계산 프레임 | 제작 기준 |
|---|---|---|---|---|
| 1타 | 8 / 0.33 | 0.09~0.17 | 3~5 | 전방 대각선 위→아래 |
| 2타 | 8 / 0.33 | 0.08~0.16 | 2~4 | 전방 아래→위 |
| 3타 | 10 / 0.40 | 0.14~0.24 | 4~7(끝 경계) | 넓은 회전 베기 |
| 4타 직격 | 10 / 0.56 | 0.22~0.34 | 4~7(끝 경계) | 머리 위에서 내려찍기 |
| 4타 충격파 | 같은 시트 | 시작0.34 | **7** | 도끼 지면 접촉 |

4타 균등 간격의7프레임 시작0.336초를 정확한0.34초로 맞추려고 `[0,.056,.112,.168,.224,.28,.34,.396,.452,.508,.56]` 경계를 기록했습니다. 4타4프레임에는 생성된1타 하강 베기 포즈를 재사용했고,1타8프레임은 별도 생성 대기 포즈로 보완했습니다. 기록: `assets/source_art/stage4/player_packing.json`.

구르기 경계는 `[0,.03,.08,.13,.18,.23,.28,.33,.38,.43,.48]`. 1프레임 선딜,2~6 무적 중 말아 구르기,7~10 일어서기. 중앙5포즈는 별도 생성했으며 게임 표시 최대 높이48px입니다.

F1 화면은 `screenshots/stage4_attack_1_hitbox.png`~`stage4_attack_4_hitbox.png`. **넓은3타 판정은 그림보다 멀리 뻗습니다.** 640프레임·8px 여백·배율0.30의 전방 표현 한계93.6px는 기존3타 판정 끝126px보다 최소32.4px 짧고 실제 포즈별 차이는 더 클 수 있습니다. 기존 판정·크기를 유지했으며 완전 일치를 주장하지 않습니다. 공중4타도 같은 시트·발 앵커라 내려찍기의 공중 자연스러움은 직접 플레이로 추가 미술 검토가 필요합니다.

## 참고 이미지와 NPC

사용자가 알려준 대로 **이전 대화에서 생성해 저장한 정면 포함 디자인 이미지**를 재사용했습니다. 왕족 아틀라스 위에서부터 루갈반다·닌순·샴하트·팝수칼, 인안나는 기존 후보3 은빛 라벤더 머리입니다. `assets/reference/<id>_design.png` 첫 열을 `assets/source_art/npc_front/`에 저장했고 새로 임의 재디자인하지 않았습니다.

니므롯 첨부는 대화상 참조로 사용했습니다. Windows `C:/Users/...` 원본은 Linux에서 읽을 수 없고 업로드의 로컬 포인터도 없어 **원본 PNG를 그대로 복사하지 못했습니다.** `assets/reference/nimrod_design.png`는 첨부를 참조해 이미지 생성한3방향 파생 디자인입니다. 곱슬 검은 머리·검은 튜닉·청동 마름모 띠·초승달 도끼와 스파이크를 기준으로 제작했습니다.

샤마쉬·아야는 같은 신규 디자인 시트에서 측면·정면을 추출했습니다. 황금빛 머리, 실용적인 차콜/아이보리·복숭아 안감 코트, 작은 태양 장식이며 후광·오라·의식복 없음. 비율1.04/0.98, 팝수칼은 여성·1.00입니다. 머리·옷의 큰 디자인은 동일 시트 기반이며 작은 장식의 완전한 일관성은 사람이 검토할 항목입니다.

7명 FRONT≤140, SIDE≥220, 히스테리시스140~220, 유예0.5초, 전환 페이드0.12초. 거리700px 밖에서는4~8초마다 정면/초기 측면으로 둘러봅니다. 토인은 기존 좌우 방식, 이름표는 루트 독립 노드로 뒤집히지 않습니다. 기존5가지 가독성 처리 유지.

토인 시트는 배율1.30으로 재사용합니다. 검증만 원본 제작 때 alpha>12 기준 **359px**를 데이터에 기록했습니다. 새363px를 옛 시트에 소급하면 변경하지 않은 일부 포즈에서 잘못된 실패가 생기기 때문입니다. 원본 키 비율·표시 배율·±3% 허용치는 완화하지 않았습니다. 기존C/문지기0.962는 샴하트0.960보다 조금 큽니다. 확대 선명도를 더 높이려면 **토인 시트 재생성 권장**입니다.

## 이미지·오디오

**이미지 미생성 목록: 없음.** 필수 PNG147개 모두 존재하고 검증 통과. 생성 원본을 크로마키·크롭·리사이즈·앵커·시트로 처리했으며 숨쉬기·내부 림라이트만 허용된 PIL 파생입니다. 타일은 기존 경계 픽셀 블렌드. `_draw()`는 디버그 판정 전용.

기존 괴수·토인·성 대문·앞뜰 배경 재사용. 목적·경로·크기·프레임·배경 처리·완성 요청은 `assets/image_prompts/stage4_*.md`, 실제 원본 요청과 패킹은 `assets/source_art/stage4/`에 보존. 하단 전경 대신 생성512×512 underground_fill을 카메라 하단까지 반복.

황무지 BGM48초,44100Hz 모노16bit WAV, 드론·금속 타악·바람 합성. 동일 BGM이면 이동 때 스트림 유지. 효과음은 기존 음원 재사용. 음원 측정: 피크-3.0004dBFS, 루프 경계 차151PCM단위로 파일 내 최대 인접 차359보다 작습니다. 스피커 청감은 미실행.
