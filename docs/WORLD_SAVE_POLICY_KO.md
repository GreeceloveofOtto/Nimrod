# 연속 월드 저장 정책

자불리스탄에서는 can_save(), save_game(), save_checkpoint(), 직접 스냅샷 쓰기와 백업 복구 쓰기를 모두 차단한다. 사망하면 흐와니라 광장으로 귀환하여 최대 HP까지 회복하고 자동 저장한다.

능력, 생명 조각 UID, 문·지름길, 압축 지도, 보스 처치와 사망 횟수는 zabulistan 블록으로 저장·복원한다. 결정과 임시 전승 수집품은 사망 시 소멸한다. 일반 괴수의 처치 기록은 한 시도 동안 유지하고, 광장 귀환 후 새로 내려가면 초기화한다.

저장 스키마 1의 누락 필드는 빈 진행과 0회로 마이그레이션한다. 불러오기 위치는 광장이며, 자불리스탄 재진입 위치는 착륙지다. 새 저장 지점은 추가하지 않았다. 니므롯의 저장 지점은 유지하고 전체 사망 수 메타데이터만 기존 체크포인트에 갱신한다.

F5는 저장 파일, 자불리스탄 영구 진행과 사망 횟수까지 완전히 초기화한다.
