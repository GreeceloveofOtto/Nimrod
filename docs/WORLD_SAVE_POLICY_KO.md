# 자불리스탄 임시 저장 정책

단검 전달 직후 흐와니라 광장의 character 체크포인트를 한 번 저장한다. 라오다스타흐마의 다음 대화가 끝나면 자불리스탄으로 출발한다.

`data/world/zabulistan/world.json`의 `save_enabled: false`가 모든 디스크 저장 경로를 차단한다. `can_save`, `save_game`, `save_checkpoint`, `_write_snapshot`, 손상 파일 복구 쓰기를 함께 검사한다. `data/world/save_points.json`은 비활성이고 방의 `save_point`는 null이다.

월드 탐험 중 사망하면 마지막 방의 마지막 입구로 돌아온다. 능력·생명 조각·결정·수집물·방 방문 기록·처치한 보스는 세션 메모리에 남는다. 일반 적은 방을 떠나면 해제되고 다시 들어올 때 전부 생성한다. 아직 처치하지 않은 보스는 HP를 초기화한다.

종료 후 이어 하기를 선택하면 광장 체크포인트의 위치·단검·기존 이야기를 복원한다. 자불리스탄에서 얻은 능력·아이템·지도는 사라진다. 이는 저장 지점을 만들기 전의 의도된 임시 정책이다. 구 13단계 stage20/21 저장 형식과 니므롯 저장 형식은 변경하지 않는다.

F5는 저장 파일과 백업을 삭제하고 두 캐릭터의 진행·무기·월드 세션을 모두 비운 뒤 니므롯의 집에서 시작한다. 기존 규칙대로 대화·컷신·전환·지도 일시정지 중에는 실행하지 않는다.
