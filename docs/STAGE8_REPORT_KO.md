# NIMROD 8단계 보고

끼임·검은 배경·괴수 접지를 수정하고 8개 스토리 상호작용을 구현했습니다. 표시 크기와 전투 수치는 유지하면서 에셋 저장 용량을 263.54MiB에서 60.32MiB로 줄였습니다. 전체 기능 검사와 다운로드 ZIP 검증의 최종 결과는 별도 JSON으로 기록합니다.

## 실제 프로젝트와 보존한 동작

Godot 4.3 공식 바이너리, GL Compatibility, 1280×720, 25개 레벨입니다. 실제 7단계 결과는 새 게임·사망 시작이 RearGate가 아니라 NimrodHome/Spawn_Start(x330), 맨손입니다. 이 흐름을 유지했습니다. 집 지팡이는18/18/24, 부모님 선물 도끼는20/20/20/22, HP180, 구르기0.48초/속도780, 콤보 리셋0.8초, 도끼 히트스톱0.05초를 유지했습니다. 통로9종의 표시 크기도7단계의1.5배를 보존했습니다.

## 세 가지 버그

1. 낮은 일방향 발판: 일반 공간 쿼리에 일방향 면이 포함돼 서기를 막았습니다. 공용 `_solid_overlaps`는 one_way 메타 또는 CollisionShape2D의 일방향 속성을 가진 면을 제외합니다. 서기·공격·웅크리기 해제·점프의 여유 공간 검사는 이 경로를 사용합니다. 구르기 종료는 서기 → 반대쪽24px 이내 밀기 →90px 웅크리기 →48px 기어가기 순서입니다. 벽에 붙은 경우도0.8초/3px 정체를 검사합니다. 이미 같은 안전 위치에 있는 정상 경계 충돌은 무의미한 순간이동으로 기록하지 않습니다. 구르기 이동은46px 박스 폭의 절반 이하로 나눕니다. 고체100px 터널은 계속 서기를 막습니다.
2. 검은 나무 박스: wall_trunk_tile은 배경이 검게 구워진 이미지였습니다. 이미지 생성 도구로 전면 껍질·이끼 질감160×512를 새로 만들었습니다. 고체80×140 표시에는 중앙160×280을 크롭합니다. 투명/불투명 분류430개와 검은 가장자리·연결된 단색 배경·마젠타 검사를 적용했습니다.45개 기존 배경/타일은 RGB×0.93+18 색보정으로 검은 가장자리를 제거했으며 알파는 보존했습니다. 전체 배경 재생성은 하지 않았습니다.
3. 공중 부양: 실제 숲2층 마귀는4개체가 아니라7개체였습니다. 모두 눈에 보이는 가지 발판(240×64 이미지, 실제 윗면은 이미지 y37/120)과 줄기 소품을 추가했습니다. 가지 지지 줄기는 기존 cedar_stump 이미지를 재사용하며 다음 하단 발판까지 이어집니다. 지상형은600px 레이캐스트로 스폰을 지면에 맞춥니다. 초기 바닥 판정을 바로 얻도록 지면 위 여유를0.01px로 설정했습니다. 부유형과 천장/벽에 매달리는 wall_diver는 지상 접지 검사에서 제외합니다.

## 대화 시스템

모든 대화는 get_tree().paused=true로 게임 시간을 멈춥니다. freeze:false도 예외가 아닙니다. Dialogue·카메라·대화용 도끼 선물 연출·Audio만 정지 중 동작합니다. 월드 AI/물리/프레임/위험 지대/쿨다운은 정지합니다. BGM은 그대로 유지됩니다.

대화창은 화면 우측 중앙,1280 기준520px, 범위400~560px, 오른쪽32px, 최소 높이150px입니다.22pt 한글과20pt 화자 이름 칩, 가는 금색 테두리·12px 모서리를 사용합니다. 니므롯 칩은 청동색, NPC는 금색입니다. 화자 NPC는 정면을 바라보고 몸과 이름표를 잠시 밝힙니다. 카메라는1.35배/0.35초(혼잣말1.2배)이며 두 화자를 왼쪽 약1/3에 배치하고 레벨 경계를 지킵니다. 종료 후0.35초에 복원하고 E를0.2초 억제합니다. 자동 타자0.04초/글자, 줄 유지max(1.6,0.05×글자수)초입니다. 대화를 취소하면 대기 중 타이머도 해제해 종료 시 코루틴 누수를 방지합니다.

기존 한글 폰트에 새 대사의104개 글자가 빠져 있어 같은 NimrodUIKorean 폰트를404문자 서브셋으로 갱신했습니다. 테스트에서 대사 모든 글자의 실제 글리프를 검사합니다.

## 이미지와 용량

신규 생성은 wall_trunk_tile 1개입니다. 마귀 가지·줄기7곳은 기존 생성 이미지를 재사용했습니다. 미생성 에셋은 없습니다. 생성 원본/변환 전/이전 시트/미사용5개 타일은 archive/에 보존하며 GitHub와 슬림 ZIP에서는 제외합니다. archive 원본을 필요로 하는 재패킹·전체 화소 재비교는 클라우드 작업 공간에서 실행해야 합니다. 다운로드에는 플레이·개발·내장 화소 표본 검증에 필요한 파일을 포함합니다.

용량 전후 폴더 예산, 상위40개 파일, SSIM/색차와 최종 ZIP은 SIZE_REPORT_KO.md를 참조합니다. 저장 해상도 축소·트림·손실 RGB WebP를 사용했으며 새 이미지 패킹에도 density_limits/image_policy를 적용합니다. 논리1,512프레임의 연속 중복 검사는 수행했으나 삭제 기준을 만족한 프레임은0개였으며 모션 타이밍은 유지했습니다.
