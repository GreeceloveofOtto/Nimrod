# contact_shadow

목적: 3단계 게임 에셋.
경로: assets/fx/contact_shadow.webp
규격: [256, 64], 프레임 1.
배경: 투명 스프라이트는 #FF00FF 크로마키, FX는 생성 알파 보존, 하늘·타일·디자인은 불투명.
후처리: crop/resize/anchor/pack, 타일은 원본 경계 블렌드만.

완성 프롬프트:

2D side-view game asset, dark fantasy, ancient Mesopotamian Uruk atmosphere, hand-painted look, clean readable silhouette, consistent with the Nimrod character sprite sheets, no text, no watermark
Produce a transparent PNG game FX atlas with TWO horizontal equal-height rows, no colored background, truly transparent background. Row1 ONLY a soft warm ivory-white elliptical radiant pool / diffuse glow, brighter soft center, entirely smooth translucent gradient fading to fully transparent outer edges, no rings, rays or painted object, horizontal 2:1 aspect glow. Row2 ONLY a soft dark gray-black elliptical contact shadow, horizontal 4:1 aspect, darkest softly transparent center, feathered edges fully transparent, no object or light in shadow. Both comfortably contained, isolated, no text. Minimal simple readable FX painted by image tool, large 1024x768 output. These are image FX behind NPCs, no characters.
